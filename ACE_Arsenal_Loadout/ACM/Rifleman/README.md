# Rifleman

## 📌 Descripción del Rol

El **Fusilero (Rifleman)** es el operador de infantería estándar dentro de la escuadra. Su función principal es proporcionar fuego directo, mantener la seguridad del equipo y apoyar las maniobras del elemento durante avances, defensas, repliegues o limpieza de zonas.

Este rol opera integrado con su escuadra, cubriendo sectores asignados, respondiendo a contactos enemigos y apoyando a roles especializados cuando sea necesario. Su configuración se mantiene ligera y funcional, utilizando únicamente uniforme y chaleco, sin mochila, lo que favorece la movilidad y reduce la fatiga durante la operación.

El uniforme contiene el equipo básico de supervivencia y primeros auxilios. Estos elementos permiten al operador realizar intervenciones inmediatas en caso de emergencia, incluso antes de que el médico despliegue equipo especializado.

## 🦺 Chaleco

### 📖 Descripción

El chaleco contiene el equipo táctico de combate inmediato, incluyendo munición, herramientas de control y elementos de señalización. Este equipamiento permite al operador defenderse y operar dentro del combate activo.
